# Незваные гости

Браузерный бытовой хоррор от первого лица: квартира из трёх комнат, шесть пауков, шесть инструментов и счёт за разбитое имущество. Спокойные эпизоды сменяются тревожными без постоянных скримеров.

## Запуск

Нужны **Node.js >=20**, npm и настольный браузер с **WebGL 2** и **Pointer Lock**. JavaScript ES modules, Three.js **0.170.0**, Vite **6.0.5**. Аккаунты, backend и внешние сервисы для игры не нужны.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (по умолчанию `http://localhost:5173/`). Не открывайте `index.html` через `file://`. Дождитесь загрузки моделей, нажмите «Войти в квартиру» и разрешите захват мыши. При отказе игра останется на паузе; «Продолжить» повторяет запрос.

```sh
npm test
npm run build
npm run preview
```

Production-сборка находится в `dist/`, preview по умолчанию — `http://localhost:4173/`. Порты strict: занятый порт вызывает ошибку. Скрипты по умолчанию слушают `0.0.0.0` (доступны в локальной сети при разрешении firewall). Для локальной проверки: `npm run dev -- --host 127.0.0.1`. Не публикуйте dev-сервер в интернете.

## Публикация (сдача на джем)

Игра полностью статическая: `npm run build` создаёт `dist/` с относительными путями (`base: './'` в `vite.config.js`), поэтому одна и та же сборка работает на GitHub Pages и itch.io.

**GitHub Pages.** Workflow `.github/workflows/pages.yml` запускает тесты и сборку при каждом push в `main`. Один раз включите: репозиторий → Settings → Pages → Source: **GitHub Actions**. Ссылка будет вида `https://<логин>.github.io/<репозиторий>/`.

**itch.io.** Запустите `npm run build`, заархивируйте **содержимое** `dist/` в zip (чтобы `index.html` лежал в корне архива), создайте проект типа *HTML*, загрузите zip, отметьте *This file will be played in the browser*, размер окна 1280×720 и включите *Fullscreen button*. Pointer Lock в iframe itch.io работает после клика по игре.

Видео на 30 секунд можно записать позже: старт → окно с городом → смена инструментов 1–6 с эффектами → разбитая мебель → победа.

## Управление

| Действие | Ввод |
| --- | --- |
| Ходьба | W, A, S, D, независимо от раскладки |
| Осмотр | Мышь после захвата указателя |
| Атака | ЛКМ; удержание повторяет атаки с перезарядкой |
| Инструмент | 1–6, колесо или кнопка панели |
| Пауза / освобождение мыши | Esc |
| Возврат | «Продолжить» |

Тапок, газета, дихлофос, молоток, пылесос и огнетушитель имеют разные дальность, урон, перезарядку и радиус. Стены и ближайшая мебель перекрывают прямой луч; радиусные инструменты могут разбить соседние предметы. Время и ввод останавливаются при паузе, потере фокуса или освобождении указателя. Новый забег восстанавливает мебель, обнуляет ущерб и меняет seed.

## Графика и готовые ассеты

- **9 готовых моделей Poly Haven:** стул, стол, старый телевизор, ваза, коробка, диван, шкаф, потолочный светильник, молоток в руке.
- **PBR-текстуры:** старый деревянный пол и штукатурка; карты цвета, нормалей и шероховатости. Модели — 1K, поверхности — 2K.
- Лицензия **CC0**; авторы, источники и условия — [`public/assets/CREDITS.md`](public/assets/CREDITS.md). Контрольные суммы каждого файла — `public/assets/manifest.json`.
- Все ресурсы хранятся в проекте: около **22,8 МиБ**. Во время игры запросов к Poly Haven/CDN нет. В сборку включается весь каталог `public/assets`.
- Модели загружаются до меню с индикатором готовности и повтором при ошибке. Общие ресурсы используются повторно между забегами; модели вписываются в игровые габариты **без растягивания**.
- Три комнатных источника с мягкими тенями, холодный свет окон, направленный свет игрока, ACES tone mapping, умеренная виньетка и мелкое зерно. Спокойствие — 18 секунд, тревожный режим — 10 секунд. DPR ограничен 1,5; радиаторы инстансированы.
- Старт, пауза и результаты поверх игровой сцены; компактный HUD и собственные SVG-силуэты инструментов вместо декоративных карточек.

При необходимости восстановить ассеты: `node scripts/download-assets.mjs`. Это **ручная** подготовка с использованием публичного API Poly Haven, не часть запуска/сборки. Скрипт проверяет MD5 загрузок, сохраняет SHA-256, повторно использует совпадающие файлы и отказывается перезаписывать изменённые. Скачанные сторонние скрипты не исполняются.

## Устройство

- `src/main.js` — загрузка, ошибки запуска, очистка при HMR.
- `src/assets.js` — GLTFLoader, PBR-текстуры, единая библиотека и нормализация размеров.
- `src/game.js` — камера, ввод, Pointer Lock, оружие в руке, raycast, Web Audio.
- `src/rendering.js` — MSAA render target, tone mapping, постобработка; отдельный проход руки и инструмента с проверкой глубины, без пересечения со стенами.
- `src/apartment.js` — архитектура, окна, материалы, лампы и тени.
- `src/world.js` — мебель из снимка модели, анимация пауков, паутина, осколки, hit targets.
- `src/simulation.js` — детерминированная модель без DOM: ИИ, ущерб, cooldown, победа/restart.
- `src/movement.js` — коллизии игрока со стенами, границами и целой мебелью.
- `src/ui.js`, `src/style.css` — русскоязычные меню и HUD.
- `tests/*.test.js` — модель и интеграция настоящих glTF-буферов с Three.js.

Игровые размеры: квартира 18 × 12 м, высота 3 м; глаза 1,65 м, радиус игрока 0,22 м, скорость 3,2 м/с. Центральный проход свободен. Каждый из 15 предметов разрушаем: восемь осколков на разрушение, не более 80 одновременно; начисление ущерба однократное. Общие импортированные ресурсы освобождает библиотека, а не каждый экземпляр мира.

## Проверки

`npm test` проверяет детерминированность, снимки, все инструменты, спавн, дальность, cooldown, ущерб, победу, restart, осколки, паутину, SHA-256 ассетов, локальность glTF-зависимостей, реальные габариты/лучевые попадания по моделям, совместное владение ресурсами и свободные проходы при коллизиях.

Для инструментальной приёмки откройте `/?qa=1`: панель вызывает те же обработчики движения, выбора оружия, паузы и атаки. Она умеет перемещать камеру и направлять её на цель; «Автоохота» стреляет через настоящий raycast. **Это не подтверждает физические клавиши/мышь/Pointer Lock**: обычный режим нужно проверять отдельно. Панель не отображается без `?qa`.

Ручной сценарий: старт → все комнаты → столкновения со стенами/мебелью → шесть инструментов → разрушение → Esc/продолжение → оба режима освещения → уничтожение шести пауков → итоги → новый забег. На небольших экранах проверить отсутствие перекрытия меню/HUD; управление остаётся настольным.

## Границы

Это более реалистичная стилизация, не фотореализм. Аквариум, анимированные пауки, рука и пять инструментов остаются процедурными; молоток заменён готовой моделью. Нет мобильного управления, рекордов/сохранений, мультиплеера и новых уровней. Осколки имеют упрощённую физику, радиусные эффекты не моделируют полную окклюзию частиц. Сборка может предупреждать о JS-чанке больше 500 КБ; ассеты идут отдельными локальными файлами.
